# bin/

- `brg` — единый bash-скрипт (3.2+): транспорт бригады, ожидание, задачи, роли, дедлайны, подзадачи с резервированиями путей, `run` — тесты/сборка под глобальной блокировкой, `doctor` — проверка среды и состояния (DESIGN.md §3–§10). `bash bin/brg init <проект>` (или глобальная `brg init`) создаёт/обновляет `<проект>/.brigada/`, копирует туда себя и `brg.cmd` и кладёт блок brigada в `AGENTS.md`/`CLAUDE.md` проекта (`--no-agents-md` — не трогать их); дальше агенты вызывают `bash .brigada/bin/brg …` из корня проекта. Справка: `bash bin/brg help`, `bash bin/brg <команда> --help`.
- `brg.cmd` — шим для PowerShell/cmd на Windows: находит `bash.exe` Git for Windows (не WSL) и запускает рядом лежащий `brg`. Только ASCII и окончания CRLF (`.gitattributes`). Проверка на Windows — `WINDOWS.md`.
- `brg-global` — обёртка для человека: `bash install.sh [каталог]` ставит её как команду `brg` (по умолчанию в `~/.local/bin`). Внутри проекта запускает ближайший `.brigada/bin/brg` (из любого подкаталога), `brg init` — версией из этого репозитория, вне проекта — `bin/brg` репозитория; если `brg` проекта отличается от репозитория — подсказывает `brg init`. Переустановка нужна только после изменения `brg-global` или переноса репозитория.

Тесты: `bash tests/run.sh` (включая пинг-понг ~1 мин; пропустить — `BRG_SKIP_PINGPONG=1`), отдельно: `bash tests/pingpong.sh [-n N]`.
